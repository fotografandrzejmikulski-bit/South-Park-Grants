# Milestones

## Gate 0 — Repository integrity

Deliverables:
- reproducible package structure;
- CI passing;
- documented research thesis;
- explicit distinction between prior evidence and NeuroSteer hypotheses.

## Gate 1 — Representation

Deliverables:
- per-layer SAE baseline;
- grouped-layer implementation;
- defined angular similarity metric;
- reconstruction/sparsity/stability report;
- compute and memory comparison.

Decision: continue only if grouped representation provides a defensible efficiency/quality tradeoff.

## Gate 2 — Causal steering

Deliverables:
- feature selection protocol;
- steering coefficient sweep;
- target-effect measurement;
- off-target capability measurement;
- repeated-seed stability report.

Decision: continue only if effects are repeatable and causally attributable.

## Gate 3 — Serving

Deliverables:
- open-weight model integration;
- baseline vs steered serving benchmark;
- p50/p95/p99 latency;
- throughput and memory measurements;
- failure-mode analysis.

Decision: continue only if the intervention can satisfy a realistic operational budget.

## Gate 4 — Product discovery

Deliverables:
- one sharply scoped use case;
- 10–20 structured customer conversations;
- 3–5 qualified design-partner candidates;
- evidence that the technical capability maps to a painful workflow.

## Gate 5 — Venture readiness

Deliverables:
- technical benchmark package;
- design-partner evidence;
- product demo;
- security/deployment model;
- coherent seed narrative and financing plan.
